## 0 要点

1. **H0 是强假设，不是真实世界基线。** H0 把 NASEM 2021 Table 19-1 的送检观测总 SD（`observed_incl_sampling_and_lab`）当作本批成分的真实波动。它相对单个牧场的批次变异可能偏大，相对美国送检总体可能偏小，方向依情景而定。
2. **S2 同时改了两件事**：不确定性（窄化 SD）和风险事件（11 行 → 6 行 + 5 条计划行）。本文只处理 SD 这一半，记作 `SD-S2`；事件那一半由参照事件任务（执行指令 C）处理。
3. **S2 的窄化 SD 不是已识别的方差分解。** 48 个随机格中只有 3 格（玉米青贮 DM、NDF、淀粉，14 d true_only）用到同格的登记比值，其余 45 格借用 1/⟨withheld⟩；48 格全部标 `unidentified` / `research_scenario_assumption`。两类格的时间尺度也不一致（14 d 与 12 个月）。`SD-S2` 是 FIX_B 按“使目标 α 可达”在 opt 流上筛选出来的点。
4. **窄化 SD 的声明敏感性范围**：逐格区间 [登记下端, 1]；在区间内预先声明 5 个点（§5），不向下外推，不为可行性继续降低 SD。无解、不可达都是可以报告的结果。**区间下端（48/48 格）就是 SD-S2 点**，而 SD-S2 是按“使目标 α 可达”在 opt 流上筛选出来的（第 3 条）：下端是方法校准点，不是有据的下限；凡比较 2×2 或敏感性结果的地方都要写明这一来历（FIX3_DEF，红队 E）。
5. **随机流**：现有全部 opt / validation / test 流都归开发资料；为正式评估预留了新的根（本轮未使用）；新随机流仍不是新的真实数据（§6）。
6. **措辞**：一律写“给定模型与假设下的模型约束可靠性”；不推断疾病、产奶、利润，不称外部批次验证（§7）。

## 3 H0：观测总 SD 当作本批波动（强假设）

- **口径**：Table 19-1 的 SD 来自商业实验室送检记录，含历史采样与分析误差、跨牧场与跨年份变异；经 ±3.5 SD 与主成分得分截尾；湿化学与近红外混用（`configs/uncertainty.yaml` `base_distribution.sd_semantics`）。把它当作“本批次真实成分波动”是 H0 的定义，不是由数据识别出的事实。
- **偏差方向不唯一**：相对单个牧场、14 d 内的批次变异，它通常偏大（St-Pierre & Weiss 2015 的日采样子项目中农场间方差占 70–90 %）；相对美国送检总体，±3.5 SD 截尾（NASEM 原文）又可能使它偏小；“实验室内 SD 按样本数平均”也指向偏小，但那一条只是二手转述、未核原文。所以 H0 既不是“保守上界”，也不是“真实世界基线”。
- **后果的写法**：H0 下三个目标 α 都不可达（开发运行，`holder_verified`），应写成“在 H0 声明与该营养模型下的可行性边界”，不写成“真实牧场买不到可靠性”，也不写成“只要缩小 SD 就能解决”。候选库内无解不等于全决策域无解；训练情景的最小违约只对那批情景与那套模型成立。
- **不因不可行而改变 H0**：不降低 H0 的 SD、不删行、不改 α、不改界值。窄化 SD 另作声明情景（§4、§5），与 H0 并列报告。

### 4.2 为什么不能称为已识别的方差分解

1. 比值是项目自行计算的推断（【推断】）：分子来自已发表的方差分量汇总表，分母是 NASEM 送检观测 SD；两者来自不同样本、不同实验室与不同年份。
2. 分子本身：日采样子项目只有 OH、VT 的 11 个牧场，月采样 47 个牧场，均非随机抽样，原文没有方差分量的置信区间；12 个月的“真实月间 SD”是用日采样子项目的采样与分析方差去扣减商业实验室残差得到的，隐含两个子项目误差相同（若商业实验室误差更大，月间真实方差被高估）。
3. 45/48 格的比值是借来的：该原料或该成分没有任何登记来源。
4. 原表转录经调研笔记，关键表的浏览器抽查仍待用户（B-320，`blocked`）。
5. 代码侧已把 48 格全部标为 `variance_basis = unidentified`、`provenance_status = research_scenario_assumption`；这些标签必须保留，不得在报告中改称“场内真实方差”“估计的方差分解”。

### 4.3 时间尺度不一致

3 个有来源格用 14 d 尺度（沿用本案例 H1 已声明的批次尺度，D-450 / D-K7-8），45 个借用格的比值来自 12 个月尺度的 DM。S2 因此不是一个单一时间尺度的世界。决策时序文档把检测结果有效期设为 {3, 14, 30} d 的情景（`docs/decision_timing_and_units.md`），14 d 本身也是研究设定。

### 4.4 SD-S2 是按可达性筛选出来的点

FIX_B 的声明规则是“取使一个目标 α 可达的最小组合”，并在声明前只用 opt 流（`root=1103/opt`）筛查：同一事件下若把玉米青贮换成 12 个月比值，最小训练违约为 15/128，α = 0.10 不可达；换成 14 d 比值后为 0/128，于是选定 14 d（`RUN_CONFIG["S2"]["screening_opt_only"]`；`audit/_parts/round2/FIX_B_record.md` 明写“选择 S2 的目标就是让 α 可达”）。所以：

- `SD-S2` 位于登记范围的窄端，是**经过可达性筛选**的声明情景，不能当作中性或中心估计；
- 在 SD-S2 上得到的“可达”“校准”“同风险比较”只说明方法在该声明情景中的行为；
- 不再在 SD-S2 之下寻找“更可行”的 SD。

### 4.5 借用值的方向无法判定

- 豆科粗饲料唯一登记的场内比值（Barrientos-Blanco 2024a 饲喂期场内合计，观测口径）为 1/⟨withheld⟩–1/⟨withheld⟩，窄化弱于 1/⟨withheld⟩；它含采样与 NIRS 误差，真实部分应更小，但小多少没有登记来源。同原料的单场单茬苜蓿干草比值（Weiss & St-Pierre 2009 表 2）窄化远强，但属特例、观测口径、对照总体不是 NASEM，未采用。
- 精料：St-Pierre & Weiss 2015 表 6–8 只有场间 SD 与残差，残差分不开；原文指出豆粕、干玉米场间差异不显著，因此按“本场均值已知”去掉场间方差的窄化对这类精料作用有限。
- 因此 1/⟨withheld⟩ 对这 45 格既不能称“保守”，也不能称“已识别”。开发预检显示名义解能量供给的离散主要来自玉米青贮 DM 通道（`reports/minimum_case_nutrition_audit.md` 要点 4，`holder_verified`），所以 S2 的可达性对玉米青贮 DM 比值（14 d 的 1/⟨withheld⟩ 与 12 个月的 1/⟨withheld⟩）特别敏感，这正是 §5 把时间尺度列为敏感性维度的原因。

## 5 窄化 SD 的声明敏感性范围（供 2×2 消融与敏感性使用）

**这是声明情景，不是置信区间，也不是识别出的范围；它不表示真实场内波动落在其中。**

**下端的来历（FIX3_DEF，红队 E）**：48 个格的下端都等于 SD-S2 的比值（`sd_range_low = ratio_SD_S2`，48/48）。SD-S2 是 FIX_B 在 opt 流上按“使目标 α 可达”筛选出来的方法校准点（§0 第 3 条、§4.4）；3 个玉米青贮格的下端恰为登记 true_only 比值中最窄的一档，45 个借用格的下端就是借用值 1/⟨withheld⟩。所以区间的锚点来自一次按可行性的挑选：它**不是**有据的下限，不能写成“窄化最多到此为止的依据”。项目没有把 SD 再往下降（符合执行指令 E3），但任何引用区间或下端点（包括 2×2 的“窄化 SD”臂）的结论都要带上这句说明。

### 5.3 使用规则

1. **不向下外推**：不得使用低于下端的值。明确排除：单场单茬干草比值（1/⟨withheld⟩、1/⟨withheld⟩ 等）、把玉米青贮 14 d 比值套到其他格、把窄化点再乘维度 a 的 s < 1、把 DM-KNOWN 受控子模型当作“窄化”。
2. **点在运行前固定**：上表 5 个点今天声明；若 2×2 消融或敏感性要用别的点，必须在区间内并在任何求解前书面声明，不得看结果后增删点。
3. **同一评估**：所有点共用同一组随机流（CRN）、同一公共物理评估器与参照事件评估（执行指令 C 的 `evaluate_reference`），各点的训练目标另记；不同母分布不要求状态字节相同，但记录各世界的模型指纹。
4. **全部报告**：每个点都报告，包括 `proven_infeasible`、`time_limit`、`not_met`，以及界与 gap；不以可行性挑选点。
5. **解读**：若只有 `SD-S2` 可达而 `SD-SRC14` 或 `SD-12MO` 不可达，结论写成“可达性依赖于无来源的借用比值 / 批次时间尺度”，不写成“窄化后可行”。研究负结果可以成立。引用 `SD-S2` 或区间下端时写明“下端 = 按可达性筛选出的方法校准点，不是有据下限”。
6. **与维度 a 分开**：维度 a（0.667–1.5 的整体缩放，含 > 1）另行报告，两者不叠加。
7. **算力**：运行须在获授权算力上、冻结代码快照后执行（执行指令 F）；本轮只声明，不运行（Mac 不做重计算）。
8. **将来**：若取得有来源的场内方差分解（B-108、B-104 等），按新版本登记并重新运行；本范围与旧结果保留为开发历史，不合并成同一试验。

### 5.4 与 2×2 消融的对应

| 事件 \ SD | `SD-H0` | `SD-S2` |
|---|---|---|
| 完整 11 行概率事件 | = H0（已有开发运行） | 新格 |
| 6 行事件 + 5 条计划行 | 新格 | = S2（已有开发运行） |

“窄化 SD”臂 = 区间下端 = 按可达性筛选出的 SD-S2 点（方法校准点，不是有据下限）；报告 2×2 时与结果写在一起。两个新格在 FIX_B 声明前的 opt 流筛查中已有最小训练违约（`SD-S2` × 11 行：65/128；`SD-H0` × 6 行 + 计划行：52/128，已证；`holder_verified`，复核方未复算），但没有 validation / test 评估，也没有经过统一参照评估。四个格都回到同一参照评估器。从 `SD-H0` 到 `SD-S2` 的变化改变的是**问题的声明**（不确定性假设），不是方法改进；6 行指标的改善不能冒充 11 行指标的改善。

## 7 结论措辞

### 7.1 通用句式

“在〈层级〉声明（〈一句话写出方差口径与事件〉）与本项目实现的 NASEM 2021 固定版本营养模型下，〈配方 / 方法〉的模型约束联合违约率为〈值〉（Monte Carlo 误差：〈区间〉；一牛、一库存、一价格情景）。”

“可靠性”只指声明分布下模型约束的满足频率；本项目的营养模型不是全功能 NASEM 软件，也没有经过动物验证。

### 7.2 需要改写的说法

| 不能这样写 | 改为 |
|---|---|
| 真实牧场 / 现场的违约风险为 … | 给定模型与〈层级〉假设下的模型约束违约率为 … |
| 该配方会导致能量负平衡、酸中毒、疾病、减产或利润损失 | 该配方在模拟状态中违反模型约束〈id〉的比例为 …（不推断动物结局或经济结局） |
| H0 是真实世界基线 / 保守估计 | H0 声明：送检观测总 SD 当作本批波动（强假设） |
| 窄化后配方可行 / S2 比 H0 节约 … | 在声明窄化情景 SD-S2 与 6 行事件下 α 可达；与 H0 口径不同，成本差不称节约 |
| 场内真实方差 / 估计的方差分解 | 由项目推断比值与借用比值构造的声明情景（`unidentified`） |
| 经独立测试集 / 外部批次验证 | 同一声明分布下的新模拟流；没有外部验证 |
| 结论适用于一般牧场 | 结论限于本开发案例的一牛、一库存、一价格情景与所列假设 |

### 7.3 可以写的负结果

- “在 H0 声明下，训练情景内的最小可达联合违约为 …，候选方法在三个 α 下都未达到目标；这是该声明与模型下的可行性边界。”
- “可达性只在 SD-S2 成立，在只窄化有来源格或改用 12 个月尺度时不成立”（若运行结果如此）。
- “在所列相关与 SD 情景下，方法排序不稳定 / 稳定”。
