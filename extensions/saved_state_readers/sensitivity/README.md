# Final-policy fMCP saved-state sensitivity add-on

This is a post-hoc hypothetical model sensitivity analysis of 96 already frozen policy-cell records. It produces 480 risk/energy records and 360 same-state descriptive comparisons. It does not generate states, train, reselect recipes, overwrite the core, or change original experiment certificates.

Requires the unchanged extracted private R7 core, with input_manifest.csv SHA256 65527b679a2158123b95f7f74b0ce983be29bd3f20d3255c54ce7a970e632571. The core is supplied separately under a lawful author-controlled review arrangement; this local add-on does not establish redistribution rights or external reviewer access.

Tested with Python 3.14.7 and the requirements listed here. The original core dependencies must also be installed. Run from any directory:

```sh
python /path/to/addon/reproduce_final_fmcp_sensitivity.py --core /path/to/extracted_R7_core --output /path/to/a_new_output_directory
```

The output directory must not exist. All 460 required inputs are verified against the frozen hashes before and after execution. The runner imports the unchanged core evaluator and forbids random draws. It checks 96 baseline label/count/upper identities, reconstructs actual supplied DM from the saved actions and DM arrays, evaluates all 9,600,000 level-policy-state transformations, and checks deterministic energy-boundary/undefined/uniform probes against the original canonical evaluator at all five levels. This is not independent nutritional-algebra regeneration or a full canonical recomputation of all 9.6 million positions.

The levels are the inherited hypothetical fMCP multipliers 0.8, 0.9, 1.0, 1.1 and 1.2, with fixed original targets and actions. The rate table includes post-hoc diagnostic exact binomial upper bounds using a separately declared 0.05/10,000 budget. They are not new prospective certificates or measured robustness claims. Pair tables contain no new significance tests. Original formal results and all scientific inputs remain untouched.

Safe outputs contain counts, proportions and normalized shortage metrics; the private directory holds probe indices, hashes and numerical diagnostic errors. expected_safe_results preserves the actual first-run CSVs, to compare a reviewer rerun without treating them as independent evidence.

Unknown row masks are retained. Event-unknown counts may fall when an energy violation becomes known; those states are still failures. Conditional violation severity is averaged over each rule's own violating states, not a common principal subset. No measured microbial range, full microbial module, animal/field outcome, actual intake or complete NASEM validity is established.
